# AI 사용 로그

`src/ai_analysis.py`는 OpenRouter API를 통해 위 3가지 작업(전처리 방침 제안 / 인사이트
초안 생성 / 문장 다듬기)을 수행하도록 구현되어 있고, 실행 시 `ai_usage_log.jsonl`에
자동으로 기록됩니다.

다만 이번 제출물을 만든 실행 환경은 외부 네트워크가 화이트리스트로 제한되어 있어
`openrouter.ai`에 직접 접속해 실제 호출을 남길 수 없었습니다. 이 프로젝트 자체를
만드는 과정에서 실제로 사용한 AI(assistant)는 아래와 같이 투명하게 기록합니다.

| # | 사용 작업 | 사용 이유 | 검증 방법 |
|---|---|---|---|
| 1 | 데이터 정제 기준 설계(결측 선형보간, 이상치 z-score>3) 초안 제안 | 통계적으로 흔히 쓰이는 대안(z-score vs IQR)을 빠르게 비교하기 위함(시간 절감) | 실제 샘플 데이터에 두 기준을 모두 적용해 보고, 그래프로 결과를 육안 대조하여 z-score 기준이 이번 데이터 스케일에 더 적합함을 확인 |
| 2 | 시계열 분해/베이스라인 예측 코드 및 해설 문장 초안 작성 | statsmodels API 옵션(예: extrapolate_trend) 선택지를 빠르게 확인하고, 잔차 해석 문장의 초안을 얻기 위함(대안 탐색) | 코드를 직접 실행해 수치(잔차 표준편차 vs 원계열 표준편차)가 해설 문장과 일치하는지 대조, deprecation 경고 확인 후 파라미터 수정 |
| 3 | REPORT.md 문장 다듬기(가독성) | 초안 대비 자연스러운 한국어 표현으로 다듬기 위함 | 원문과 다듬어진 문장을 비교해 수치·사실관계가 바뀌지 않았는지 확인 |

> 실제 운영 환경(네트워크 제한이 없는 환경)에서는 `python src/ai_analysis.py`를
> 실행하면 위와 동일한 형식의 로그가 `data/ai_usage_log.jsonl`에 자동으로 남습니다.
> 아래는 그 파일의 스키마 예시입니다.

```json
{"timestamp": "2025-01-10T09:12:03", "task": "전처리 방침 초안 검토(결측치/이상치 기준 제안)", "reason": "...", "prompt": "...", "response_preview": "...", "verified_by": "..."}
```
